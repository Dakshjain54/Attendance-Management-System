# 📊 Attendance Management System

A simple **Attendance Management System** built to manage and track student attendance efficiently.  
This project replaces traditional manual attendance methods with a digital solution that helps teachers record, manage, and view attendance data easily.

---

## 🚀 Features

- Add and manage student records
- Mark student attendance
- View attendance history
- Simple and user-friendly interface
- Organized data management
